AEROSENTINEL HIGH-RESOLUTION INPUT FOLDER
========================================

This is an INPUT folder, not an automatic commercial-imagery download folder.
Add legally/authoritatively available fine-resolution .tif/.tiff files here,
or upload them from AEROSENTINEL Intelligence -> Direct candidate path.

The background worker scans this folder even before AOI/device location is ready.
Processed results are written to:
  app\data\highres\

Freely available Sentinel-1, Sentinel-2 and Landsat analytical products are stored in:
  app\data\imagery\
